1. העלאת PDF של השפעות על תחבורה ציבורית

המחולל קורא את טבלת ״תחנות מושפעות״ בסוף המצגת, יוצר שורה לכל תחנה מבוטלת ומכין שלט A3 אופקי לכל תחנה. יש לבדוק את השיוכים לפני הפקת השלטים. אין העלאת קבצים לשרת.
לא הועלה PDF. לניתוח קובץ דרוש חיבור אינטרנט לטעינת ספריית קריאת PDF.

2. בדיקה ותיקון של התחנות

חשוב: טבלאות ומצגות PDF עלולות לאבד את סדר העמודות בחילוץ טקסט. בדקו לכל תחנה את הקווים, התחנה החלופית ושיוך הקווים אליה. ״כל הקווים״ נשאר כך עד שתזינו קווים מפורשים; המחולל אינו מנחש.

השמות יחופשו אוטומטית אחרי קריאת PDF באמצעות API תחבורה ציבורית, ללא Octobus. נדרש חיבור אינטרנט.

לצד שם התחנה יש קישור ישיר לקו-נב. בדקו את השם באתר, העתיקו אותו לשדה ושמרו אותו מקומית לשימוש בשלטים הבאים.

בהעלאת מספר קבצים, כל אירוע יישמר כ-PDF נפרד בתוך ZIP. התצוגה והדפסה הרגילות נשארות ללא שינוי.

אם לכל תחנה יש כמה תחנות חלופיות, רשמו את כולן בשדה ״קווים לחלופית / הערה״, כל אחת בשורה נפרדת בנוסח: תחנה חלופית לקווים 18, 61: פרישמן/דב הוז — 20664. שדה זה גובר על שדות החלופית הבודדת.
